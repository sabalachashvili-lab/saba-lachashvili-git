# საბა ლაჩაშვილის პორტფოლიო

მარტივი, ადაპტირებადი პირადი პორტფოლიოს ვებგვერდი, რომელიც აერთიანებს ინფორმაციას ავტორის, პროექტებისა და საკონტაქტო დეტალების შესახებ.

## ფაილები

- `index.html` — გვერდის სტრუქტურა და შინაარსი.
- `style.css` — ფერების, განლაგებისა და მობილურზე ადაპტაციის სტილები.

## გაშვება

გახსენით `index.html` ნებისმიერ თანამედროვე ბრაუზერში. დამატებითი პაკეტების დაყენება საჭირო არ არის.
